The official NASA catalog page is reachable, but the linked NASA ZIP endpoint timed out from this workspace. The raw GitHub mirror for the original FD001 training text file was reachable and supplied the real dataset used for training.

**Why:** The official archive could not be downloaded directly in this environment, while the public mirror provided the same published training file.

**How to apply:** Try the official NASA source first; if it is unavailable, use a public mirror with clear attribution. Never replace unavailable dataset rows with generated values or present them as NASA data.
